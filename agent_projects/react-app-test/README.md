# Ops Dashboard

This is a dashboard for the Ops team to monitor payments, transactions, and system components.

## Features

*   Branch selector (Taiwan, Korea, Japan)
*   Time picker (last 1hr, 3hr, 1day, 30 days)
*   Transaction statistics cards
*   AI insights
*   Temporal workflow error categorization
*   Stage-wise transaction counts
*   SLA and SLI details
*   GKE cluster health monitoring

## How to Run

1.  Install dependencies:
    ```bash
    npm install
    ```
2.  Start the development server:
    ```bash
    npm run dev
    ```
